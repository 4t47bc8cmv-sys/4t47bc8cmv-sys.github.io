Keyverse Real-Sample Hybrid Audio Packs
=========================================

Drop your custom .mp3 clips into the pack folders below.
Each folder uses the exact same four filenames:

  - hit.mp3        (plays on every correct shortcut; pitch-shifted up with combos)
  - overdrive.mp3  (layered on 5x, 10x, 15x+ combo streaks)
  - miss.mp3       (plays on wrong shortcut)
  - ambient.mp3    (optional low-volume looping background soundscape)

Folders:
  sounds/katana/   -> ⚔️ Katana & Dojo
  sounds/anime/    -> ⚡ Anime Power-Up
  sounds/harbor/   -> ⚓ Harbor & Maritime
  sounds/cyber/    -> 👾 Retro Cyber

Note: If any .mp3 file is not present yet, KeyverseAudio automatically and
silently falls back to its built-in Web Audio API synthesizer with zero errors.
