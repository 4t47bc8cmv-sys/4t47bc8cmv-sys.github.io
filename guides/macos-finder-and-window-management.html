macOS Finder, Window Management & Connect to Server (⌘ + K)

Learn how to mount office network drives, switch windows without touching the trackpad, and navigate Finder folders at full speed.

Connect to Server in Finder (⌘ + K)

Pressing Command (⌘) + K while Finder is active opens a quick connection box that links your Mac directly to an office server, shared team drive, or home storage box—without ever clicking the Go menu.

Standard Sharing: smb://

Works just like a normal login. Type the server address (for example, smb://office-drive/shared) and a standard macOS username and password box pops up.

Strict Linux/Unix Sharing: nfs://

Requires a colon before the folder path (nfs://lab-server:/export) and has no password box—your Mac’s IP address has to be pre-approved on the server’s VIP allow-list before it connects.

Essential Finder & Window Management Shortcuts

Pair Command (⌘) + K with these everyday Finder and window shortcuts to eliminate trackpad drag-and-click friction:

Shortcut Action & Plain-English Use Case
⌘ + K Connect to Server: Open the server address box in Finder to mount smb:// or nfs:// network drives.
⌘ + Shift + G Go to Folder: Jump straight to any folder path (like ~/Library or /etc) with tab-completion.
Space Quick Look: Preview any highlighted PDF, image, video, or code file instantly without opening an app.
⌘ + H / Option + ⌘ + H Hide Window / Hide Others: Hide the current app, or hide every other open app for instant focus.
⌘ + ` Cycle App Windows: Switch cleanly between open windows of the same application.

Mastering Finder Views, Path Bars, and Moving Files

Most Mac users treat Finder like a static folder window and never touch its keyboard-driven layout modes. Pressing ⌘ + 1 switches to Icon View for visual thumbnails, ⌘ + 2 switches to List View with expandable folder trees (tap the Right Arrow key to expand a folder inline), ⌘ + 3 opens Column View for rapid multi-level browsing, and ⌘ + 4 launches Gallery View for photo and video inspection.

Reveal Where You Are & Move Files Without Duplicating

  • Breadcrumb Path Bar (Option + ⌘ + P): Displays your exact folder hierarchy along the bottom of the Finder window. You can drag files directly onto any parent folder in the breadcrumb bar to move them in one motion.
  • Disk Space Status Bar (⌘ + /): Shows how many items are in the current folder and exactly how much free SSD storage remains on your Mac.
  • Cut & Paste Files (⌘ + C, then Option + ⌘ + V): Unlike Windows, macOS disables ⌘ + X on files so you can never accidentally lose a file if you forget to paste. Copy with ⌘ + C, navigate to the destination folder, and press Option + ⌘ + V to move the original cleanly.
  • Show Hidden Dotfiles (⌘ + Shift + .): Instantly reveals or hides Unix configuration files like .env, .git, and .zshrc inside any Finder window or Open/Save dialog.

Window Wrangling Without the Mouse

When your screen fills up with overlapping Finder windows, browsers, and editors, three shortcuts restore order in under a second. Press ⌘ + H to hide the active app, or Option + ⌘ + H to hide every other app on your desktop except the one you are currently using. To cycle exclusively between multiple open windows of the same app (such as three Finder windows), press ⌘ + ` (the backtick key right above Tab). Finally, press Control + Down Arrow for App Exposé to tile every open window of your current application side by side.

Troubleshooting SMB vs. NFS Network Shares

If ⌘ + K fails to mount a network share, check the protocol prefix first. Windows PCs, Synology/QNAP NAS boxes, and macOS File Sharing servers use smb://hostname/sharename and authenticate with your username and password. Linux and Unix servers using NFS require nfs://hostname:/export/path—note the colon before the export path—and validate your Mac’s local IP address against the server’s /etc/exports allow-list rather than prompting for a password.
